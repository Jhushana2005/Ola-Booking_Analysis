# Ola Booking Analysis 🚖

## 📌 Project Overview
This project analyzes Ola ride-booking data using SQL and Power BI to identify booking trends, customer behavior, ride cancellations, and business performance. The goal is to transform raw booking data into meaningful insights that can support data-driven decision-making.

## 🎯 Project Objectives
- Analyze total bookings and successful bookings.
- Identify booking statuses and cancellation patterns.
- Examine customer and driver cancellation reasons.
- Analyze ride distance, booking value, and payment methods.
- Build an interactive Power BI dashboard to visualize key performance indicators (KPIs).
- Use SQL queries to answer business questions and extract actionable insights.

## 🛠️ Tools & Technologies
- **SQL:** Data querying, filtering, aggregation, and business analysis.
- **Power BI:** Interactive dashboards and data visualization.
- **DAX:** Measures and calculated metrics for KPI analysis.
- **CSV:** Dataset storage and data import.
